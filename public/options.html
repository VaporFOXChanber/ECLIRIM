Calibration Wizard · かんたん設定

3つの質問に、好みの絵を選んで答えるだけで、照明の設定をまとめて作ります。作った設定は、使うと決めるまで保存されません。

    おすすめの設定ができました

    絵は、実際の照明と同じ描画をテスト用の色で動かしたものです。お使いの画面や部屋の明るさを測っているわけではありません。Pulse Engine（音の解析）のオン／オフ、ゾーン別の調整、UI Guard は、この設定では変わりません。

    PREVIEW

    上は実際の照明と同じ描画です。下のグラフは、画面の縁（左端）から内側（右）へ向かう光の濃さで、点線は Edge Light の標準の形です。

    Glow Designer

    光の形を作ります。どちらのスタイルも、光がいちばん強いのは画面の最外周で、内側へ向かって弱くなります。

    しくみ・使える場面
    • Edge Light。これまでの照明です。縁に細い芯があり、そのすぐ内側に強いにじみ、さらに内側へ薄い広がりが続きます。4つのスライダーがすべて 50% のとき、0.9.0 までと同じ形です。
    • Soft Halo。芯を作らず、縁からなだらかに落ちる1つの光にします。辺に沿って隣の色とも混ざり、壁に当てた間接照明のように見えます。
    • 光源の太さ。いちばん強く光る部分の幅です。拡散曲線。落ち方の形で、低いと縁で急に落ちて長く尾を引き、高いと縁の近くを保ってから落ちます。減衰。内側へどれだけ早く消えるか。柔らかさ。芯の境目のぼかしと、辺に沿った色の混ざり具合です。
    • 「光の幅」「光の拡散」（基本設定 タブ）は、この形が届く範囲と量を決めます。DRM互換描画の光にも、この形が使われます（辺に沿った色の混ざり具合を除く）。

    照明の見た目

    サイト専用のプロファイルに保存できる設定です。

    すべてのサイトで共通

    ここはプロファイルに含まれません。どのサイトでも同じ値を使います。

    MacのChromeでは、Netflix・Prime Videoなどの保護された映像から色を取り出せません。初期設定では光らせません。固定の照明を選んでも、映像には連動しません。

    UI Guard

    光の下にある操作UI・字幕・文字を読みやすく保ちます。サイト専用のプロファイルに保存できます。

    しくみ・使える場面
    • しくみ。光が濃くなる縁の近くに、ボタン・リンク・入力欄・アイコン・文字があるかを、ページに問い合わせて調べます（クリック位置の判定と同じ方法で、画素は読みません）。文字は「あるかどうか」だけを見て、内容は読みません。
    • 弱め方。見つけた場所とそのすぐ周りだけ、光の濃さを上限まで下げます。もともと上限より薄い場所は何も変えません。Overkill のような強い設定ほど、効く範囲が広がります。
    • 見つけられないもの。動画に組み込まれた標準のコントロール、canvas の中に描かれたUI、クリックを受け取らない要素（一部の字幕など）、別サイトの埋め込みの中身。ポインターのまわりを弱める機能が、その備えです。
    • 使えない場面。DRM互換描画の光は、ページの合成でChromeが作るため、掛けられません。

    Adaptive Brightness

    映像全体の明るさに合わせて、光の強さを自動で整えます。サイト専用のプロファイルに保存できます。

    しくみ・使える場面
    • 暗い場面。明るいゾーンの光だけを抑えます。暗いゾーンの光はそのままなので、暗い色は暗いまま光り続けます（Color Engine の Shadows と一緒に働きます）。
    • 明るい場面。光を全体に下げて、眩しさを抑えます。明るいゾーンがそろって上限に張り付くのも減ります。
    • 中くらいの場面。何も変えません。変化はゆっくりで、時間の平滑化と Flash Limiter をそのまま通ります。
    • 使えない場面。映像を解析できる照明（映像に連動 · RGB解析、タブ取得）でのみ働きます。固定の照明・Music Mode・DRM互換描画では働きません。

    Color Engine 2.0

    色の読み取りと階調です。サイト専用のプロファイルに保存できます。

    しくみ・使える場面
    • Shadows。暗い場面の色をどれだけ残すか。上げるほど、暗い色が「消える」のではなく「暗く光る」ようになります。ごく暗いところ（色がノイズでしかない明るさ）は、色を付けずに無彩色にします。
    • Highlights。明るい側の丸め方。上げるほど早めに丸め、明るいゾーン同士の差を残します。ゾーンの中の白い部分に色が薄められるのも抑えます。
    • Vibrance。くすんだ色ほど大きく、鮮やかな色は控えめに彩度を足します。ディスプレイに出せない鮮やかさは、色相を保ったまま収めます。
    • HDR。HDRの映像かどうかは検出して Diagnostics に表示します。ただし、ページから読める画素はChromeがSDRへ変換したあとの値で、HDRの明るさそのものは取り出せません。光もSDRで描きます。

    Light Director

    外周の色に加えて、映像の中の光源と急に現れた光を、近い辺へ届けます。映像より目立たないよう、初期設定は控えめです。

    Dynamic Light Trails

    働きかた

    しくみ・使える場面
    • 光源の候補。まわりよりずっと明るい場所を光源の候補として扱います。明るいだけで光っていないもの（白い服、明るい壁）も候補になることがあります。
    • 急に現れた光。画面の一部だけが急に明るくなった場所に、短く反応します。場面の切り替わりや画面全体の明滅は、この対象から外します。
    • 動きの方向。フレームの差からは「どこが変わったか」しかわかりません。方向は、光源の候補の中心を追って求め、進む先へ少しだけ先回りして光らせます。
    • 字幕とロゴ。画面の上下にある横長の帯（字幕の形）は光らせません。何分も変わらない明るい部分（局のロゴなど）は、ゆっくり対象から外します。形と時間だけで判断するため、外れることがあります。
    • 点滅。くり返し明滅する光は、自動で弱めます。Flash Limiter と時間の平滑化は、ここで足した光にもそのまま掛かります。
    • 使えない場面。映像を解析できる照明（映像に連動 · RGB解析）でのみ働きます。DRM互換描画・固定の照明・保護された動画では働きません。

    Pulse Engine

    再生中の音を低・中・高の3つの音域で聞き、ビート・爆発音・効果音に合わせて光の強さを変えます。色は映像のままです。

    Pulse Depth は、画面で見える光の濃さをどれだけ動かすかです（40% で、ビートのとき最大1.6倍、ビートの間は約0.76倍）。Beat Wave を上げると、低音のビートが下辺の中央から左右の辺を通って上辺へ走ります（100% で約0.32秒）。0% にすると、すべての辺が同時に動きます。Beat Bloom は、ビートのたびに光が画面の内側へ広がる量です（100% で、光の届く深さが最大1.8倍）。0% にすると広がりません。UI Guard がオンのときは、広がった光がボタンや文字に掛かっても上限を超えないよう、保護する範囲を縁の側へ広げます。

    Music Mode

    映像を使わず、音だけで光らせます。低音は下の辺を暖色で、高音は上の辺を寒色で照らし、色合いはゆっくり揺らぎます。映像のない音声プレイヤーでも働きます。

    音の扱い

    しくみ・使える場面
    • 読むのはオンにしたあとだけ。Pulse Engine をオンにするか Music Mode を選ぶまで、音には一切触れません。プリセットの適用やバックアップの読み込みで、勝手にオンになることもありません。
    • 再生音は変えません。プレイヤーの音の「写し」を受け取り、音域ごとの大きさを読むだけです。写しはどこにも出力せず、録音・保存・送信もしません。
    • 動くのは変化だけ。各音域を直近の大きさと比べ、急に大きくなったところで光を持ち上げます。一定の音は、どれだけ大きくても光を動かしません。
    • Flash Limiter。音で動かした光にも掛かります。オンの間は、ビートへの反応を1秒に3回までにします。ビートの瞬間だけは、光を一度に少し（最大の明るさの8%まで）持ち上げ、同じだけ速く戻すことを許しています。それ以外の変化の速さは、映像の光と同じ上限のままです。Flash Limiter がオンの間は、Beat Bloom の広がりは半分になり、ビートで濃さを上限いっぱいまで持ち上げる動きは使いません。ビートをもっと穏やかにしたいときは Pulse Depth を下げてください。
    • 使えない場面。保護されたコンテンツ（DRM）の音は解析しません。別のサイトから配信されている音は、Chromeが読み取りを許可しません。プレイヤーがミュート中は、光は動きません。DRM互換描画では働きません。
    PREVIEW

    外側の区切りがゾーンです。クリックで選択、Shift＋クリックで範囲、⌘ / Ctrl＋クリックで追加・解除。内側の光は、実際の照明と同じ描画で表示しています。

    ゾーンの調整

    調整は辺の上の位置で保存します。ゾーン数が変わっても（自動調整を含む）、同じ場所に同じ調整が掛かります。DRM互換描画（CSS）では、ゾーン別の調整は使われません。

    Preset Library

    照明の見た目をまとめて切り替えます。適用先は、上の「編集する設定」で選んでいる対象（グローバル設定か、サイトのプロファイル）です。

    プリセットが変えるのは見た目だけです。ゾーン別の調整、UI Guard、照明のソース、Pulse Engine のオン／オフはそのまま残ります。以前の版で書き出したファイルも、そのまま読み込めます。

    JSON の読み込みと書き出し

    プリセットは1つずつJSONファイルにして渡せます。「すべての設定」は、グローバル設定・サイトのプロファイル・自分のプリセットをまとめたバックアップです（サイトへのアクセス許可はChromeが管理していて、含まれません）。読み込んだ内容は保存時と同じ検査を通し、知らない項目は捨てます。

    Site Profiles

    サイトごとに、照明の見た目を保存できます。プロファイルにはグローバル設定と違う項目だけを保存し、残りはグローバル設定に従います。そのサイトのページを開くと自動で使われます。

    プロファイルは設定を保存するだけです。サイトへのアクセス許可や照明の自動開始（「このサイトでは常に点灯」）は別の機能で、ここから許可が追加されることはありません。

    Performance Monitor

    診断の設定

    しくみ・使える場面
    • 表示する値はすべて、そのタブの中で実際に計った値です。
    • CPU使用率・GPU使用率は表示しません。拡張機能からは、タブごとの正確な値を取得できないためです。代わりに、処理にかかった時間と、予算を超えた回数を表示します。
    • 「最初の描画までの遅延」は、フレームを読んでから、その結果が最初に画面へ描かれるまでの時間です。その後の平滑化にかかる時間は含みません。
    • 品質の段階：0 = 最高、1 = Light Director が読む画素を1/4に、2 = 解析を小さくし Light Director は1フレームおき、3 = 映像解析の回数を半分に（Light Directorは継続）。

    Diagnosticsの要約 任意

    動作の状態・fps・処理時間などを添付できます。URL、タブ名、サイト別設定の名前、映像・音声は含めません。

    作成時点の値です。非表示のタブは解析や描画を休むことがあります。タブの変更や要約の更新後は、もう一度確認してください。

    バージョンを自動で添えます。Diagnosticsは、要約を確認してチェックした場合だけ含めます。
