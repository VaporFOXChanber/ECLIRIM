# Glow・UI Guard・設定比較の設計

開発者向けの実装概要です。操作方法は [日本語ガイド](../README.ja.md)、ビルドと試験は [開発者ガイド](DEVELOPMENT.md) を参照してください。

## 保存データと更新

名称はECLIRIMですが、旧CineGlowのJSONも読み込めます。`chrome.storage.local` の `settings`・`profiles`・`presets` を維持し、新規項目は移行処理で初期値を加えます。パッケージ化されていない拡張の更新では同じ展開先を使ってください。場所を変えると拡張IDが変わり、以前の保存データが見えなくなることがあります。

## Glow Designer

描画は、縁から内側への濃さ `glowProfile` と、辺に沿った色の列 `ledRow` を組み合わせます。Edge Lightは芯とにじみ、Soft Haloは芯のないなだらかな光です。どちらも縁が最も強く、内側へ減衰します。Edge Lightの4スライダーが50%なら0.9.0と同じ形です。

柔らかさは外周を輪として色を混ぜ、角を回り込みます。オフにしたゾーンは混色後もオフを保ちます。CSS互換描画は同じ形のマスクを使いますが、辺に沿った混色はありません。

## UI Guard

`document.elementFromPoint` と要素の矩形・可視性から、光の下の操作部や文字の存在を調べます。文字の内容、入力値、画素は読みません。検出は時間枠を設けて分割し、既知の要素を追跡します。細いスライダー等を扱うため、見つけた操作部と同じバーの要素も追跡します。

濃さの上限は `0.6 − 0.48 × 強さ`。描画するフレームのLEDの明るさから必要なマスク値を計算し、保護を強める側は描画前に即時適用、解除する側だけ滑らかに戻します。Beat Bloomで拡大する範囲も計算へ含めます。最外周の線は残し、もともと薄い光は下げません。ポインター付近も一時的に弱めます。

標準videoコントロール、canvas内のUI、`pointer-events: none` の要素、焼き込み字幕、`::cue`、別オリジンiframe、閉じたShadow DOMは検出できないことがあります。CSS互換描画には適用できません。

## Adaptive Brightness

黒帯を除いた映像から知覚的な明るさを平均し、暗い場面では明るいゾーンだけを抑え、明るい場面では全体を抑えます。中間の場面は変えません。場面が大きく変わると追従を速め、目標色に係数を掛けたあと、時間平滑化とFlash Limiterを通します。固定照明・Music Mode・CSS互換描画には適用しません。

## A/B比較

`compare` に `{ active, a, b, target }` を保持し、対象のグローバル設定またはサイトプロファイルを使うタブへ、選択中の見た目を重ねます。選択が確定するまで `settings`・`profiles` は変更しません。確定時は差分だけ保存し、キャンセルでは比較状態だけを消します。

照明のオン／オフ、ソース、ゾーン数は比較対象外で、通常どおり保存します。拡張の起動・更新・再読み込み時は未完了の比較を終了します。ボタン、UI内のA/Bキー、`Alt+Shift+B` で切り替えられます。ショートカットの競合はChromeの設定で変更できます。

## Calibration Wizard

光の量・幅・柔らかさの36通りを見た目の設定に変換します。すべて標準ならCinematic Balancedです。実際のレンダラーと合成色でプレビューし、適用・Bとの比較・プリセット保存を選ぶまで保存しません。音声解析のオン／オフ、ゾーン調整、UI Guardは変えません。部屋やディスプレイを測定する機能ではありません。
