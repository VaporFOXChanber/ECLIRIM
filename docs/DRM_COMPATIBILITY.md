# 保護された動画とCSS互換描画

## 利用上の制約

**macOSのChromeでは、保護された映像の色に連動する照明を作れません。** 保護映像は通常の画素取得やページ合成から分離されるため、CSS互換描画にも色を渡せません。ECLIRIMはProtected Contentと表示し、初期設定では光らせません。Cinemaプリセット・ゆっくり変化・固定カラーを選べますが、これらは映像に連動しません。

macOS以外の保護映像のCSS合成は未確認です。通常のスクリーンショットと実画面の保護映像の合成経路は異なる場合があり、スクリーンショットの光だけで実画面の動作を判断できません。

Netflix・Prime Videoでは保護されていない予告編でも、ホスト名に基づきCSS互換経路を選びます。暗号化の検出には `encrypted` と `mediaKeys` を使います。これらのサービスと暗号化動画では、再生・画質への影響を避けるためタブ取得を開始しません。途中で暗号化へ切り替わった場合も取得を終了します。鍵やライセンス通信には触れません。

## 開発者向けの描画概要

`src/render/compatibility.ts` は、透明な外周レイヤーにSVGフィルターを使う `backdrop-filter` を適用します。上下の辺は縦に深く・横に浅く、左右の辺は横に深く・縦に浅くぼかします。位置が分かるプレイヤーの余白はoffsetで詰めます。映像に焼き込まれた黒帯の位置は画素を読まずには分からないため、検出しません。

階調と彩度を整え、明るさを不透明度へ移します。暗い場面は透明になり、ページを暗い色で覆いません。マスクで外周の光だけを残し、中央は透明にします。フィルターはShadow DOM内に置き、外部から読み込みません。元のvideoのスタイル・ソース・再生速度・音量は書き換えません。

この経路は映像の画素取得、タブ取得、外部送信を使いません。固定コンテナの全画面化には光レイヤーを移動して追従しますが、video要素やiframeだけの全画面では重ねられません。

明るさ・幅・強さ・彩度・光の形は反映します。RGBゾーン解析、時間平滑化、Flash Limiter、UI Guard、黒帯検出、音声解析は適用できません。字幕・操作UIも色に混ざり、小さい動画では向かい合う範囲だけ光ります。発光が見えない場合は固定照明を選んでください。

保護なしのCORS制限動画にも使えますが、OS・GPU・Chromeによって見え方が変わります。保護解除やハードウェアアクセラレーションを無効にする回避策は実装・推奨しません。現在の検証範囲は [QA](QA.md)、操作方法は [README](../README.ja.md) を参照してください。
