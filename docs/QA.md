# ECLIRIM 0.9.9 — 検証範囲

[English](QA-0.9.9.en.md)

このパッケージでは、macOS Apple Siliconで型検査・**クライアント単体100件**・本番ビルドが成功しました。使用した既存依存の該当バージョンはlockfileと一致しています。依存の新規インストールは確認していません。

ブラウザーE2E、実際のフィードバック配送、長時間利用は、このパッケージでは再実行していません。過去版のブラウザー試験結果を、このパッケージの検証結果とは扱いません。Windows・Linux・Intel Mac、最低対応版のChrome 116、現在の商用配信サービス、HDR視聴、実機のモニター間移動は未確認です。

macOS Chromeでは保護された動画の色を取得できません。任意の固定照明は映像に連動しません。自動試験のClearKey素材は検出とフォールバックを確認するもので、商用Widevine配信や実画面での評価の代わりにはなりません。

この版はBetaです。導入・制約は [利用ガイド](../README.ja.md)、試験コマンドは [開発者ガイド](DEVELOPMENT.md) を参照してください。
