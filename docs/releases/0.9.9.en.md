# ECLIRIM 0.9.9 — Global Update (Beta)

[English guide](../../README.md) · [日本語ガイド](../../README.ja.md) · [日本語 release notes](0.9.9.md#日本語)

## English

**Beta / Pre-release · Chrome 116 or later · English and Japanese UI**

ECLIRIM adds ambient lighting inside Chrome's web page area. Edge colors follow accessible video pixels; optional Pulse Engine and Beat Bloom react to sound. Audio analysis is off by default. This is an on-page effect, with no physical lighting hardware required.

### Highlights

- English/Japanese setup, popup and settings. Choose Auto, English or Japanese; the choice persists across restarts.
- Cinema / Vivid / Ambient looks, Edge Light / Soft Halo, site profiles, presets and A/B comparison.
- UI Guard and adaptive brightness help keep page controls readable.

### Install or update

Download the attached **ECLIRIM-0.9.9.zip**, rather than GitHub's automatically generated “Source code” archive. Extract it, open `chrome://extensions`, enable **Developer mode**, select **Load unpacked**, and choose the folder containing `manifest.json`.

For an update, replace the contents of the same existing extension folder, reload the extension, then reload video pages. Keeping the folder path helps preserve the extension ID and settings. You can export a settings backup from Settings → Presets first. This Beta has not been submitted to the Chrome Web Store.

### Privacy and feedback

Video/audio analysis and lighting stay on your device; video and audio are not uploaded or recorded. **Send feedback** submits your input to the developer only when you press it. A diagnostic summary is optional and requires your review and confirmation; it excludes page URLs, tab titles, video and audio. Real feedback delivery was not re-tested for this package.

### Validation and known limits

Type checking, **100 client unit tests** and the build passed for this package.

On macOS Chrome, protected Netflix/Prime Video colors cannot be read; optional fixed lighting does not follow protected video. Windows/Linux/Intel Mac, minimum-version Chrome, fresh dependency installation, browser E2E and long sessions were not re-tested for this package. See the [validation summary](https://github.com/VaporFOXChanber/ECLIRIM/blob/main/docs/QA-0.9.9.en.md).
